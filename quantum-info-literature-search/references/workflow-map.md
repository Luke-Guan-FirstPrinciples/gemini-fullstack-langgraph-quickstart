# Workflow Map

Use this reference when the user wants the search process expanded into explicit substeps, especially for physics and quantum information.

## 1. Have a paper (warm search) and/or define the question (cold search)

### Warm search
- Start from a known paper, author, lab, collaboration, or venue.
- Extract title language, keywords, coauthors, venue, arxiv category, methods, mathematical objects, and neighboring citations.
- Ask whether the seed is foundational, frontier, review-like, or merely adjacent.
- If the seed is weak or off-target, use it for vocabulary only and quickly broaden.

### Cold search
- Rewrite the topic as a researchable question.
- Identify subfield, system, method, target result, and optional timeframe.
- Draft initial queries with canonical terms, synonyms, older terms, and adjacent-subfield terms.
- If the question is too broad, narrow by system, method, or outcome.
- If it is too narrow, relax one constraint.

## 2. Do a broad scoping search
- Use short, high-recall searches.
- Collect a starter set including reviews, recent papers, and older influential papers.
- Note recurring authors, labs, journals, methods, and frameworks.
- For quantum information, check whether the cluster is drifting into nearby subfields.
- If results are noisy, add one disambiguator.
- If results are sparse, search older or adjacent terminology.

## 3. Learn the field vocabulary
- Build a map from user language to field language.
- Record canonical terms, narrower technical terms, and nearby non-equivalent terms.
- Separate theory and experiment language when needed.
- Revise queries accordingly.
- Repeat this step whenever reading reveals better terminology.

## 4. Screen titles and abstracts
- Bin papers into core, supporting, branch, or drop.
- Ask whether each paper is directly relevant, what evidence type it offers, and whether it contributes a result, synthesis, or application.
- Note basic credibility, recency, and likely influence.
- If too many papers survive, tighten criteria.
- If too few survive, relax one criterion and repeat.

## 5. Read the most relevant papers
- Read reviews and seminal papers early.
- Then read frontier papers and close methodological neighbors.
- Extract the main claim, assumptions, method, evidence type, limitations, and relevance.
- Also rate each paper on:
  - credibility and popularity,
  - recency,
  - venue and author/lab context,
  - limited social attention.
- Use popularity carefully: citations, venue quality, lab track record, and repeated reuse all matter, but none is conclusive alone.
- Use x only as a weak priority signal for new papers or visible debates.

## 6. Use references and citations to expand, plus author, lab, and journal
- Backward citations for foundations.
- Forward citations for follow-up work and critiques.
- Author expansion for sustained research programs and coauthor clusters.
- Lab expansion for institutional lines of work.
- Journal or venue expansion for subliterature mapping.
- If a branch keeps yielding central papers, deepen it.
- If it drifts from the question, stop following it.

## 7. Track notes and references carefully
- Maintain a structured record in OpenAlex, Google Scholar, Semantic Scholar, or a companion note system.
- Save citation, summary, tags, credibility notes, recency notes, and expansion paths.
- Maintain synthesis notes across papers, not just one note per paper.
- If tracking becomes too heavy, reduce the schema to the minimum useful fields.

## 8. Repeat until the same names, ideas, papers, labs, and venues keep reappearing
- At the end of each pass, choose one action:
  - narrow,
  - broaden,
  - branch,
  - stop.
- Stop when new searches mostly reproduce known core literature and add little conceptual value.
- Continue when a major debate, method family, or subfield remains under-mapped.
